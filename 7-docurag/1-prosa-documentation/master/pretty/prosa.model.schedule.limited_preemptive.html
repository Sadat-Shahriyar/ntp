Preemption Model Compliance

A preemption model restricts when jobs can be preempted. In this module, we specify the corresponding semantics, i.e., how a valid schedule must be restricted to be compliant with a given preemption model.

... and a schedule of the jobs in the arrival sequence.
  Variable sched : schedule PState.

We say that a schedule respects the preemption model given by job_preemptable if non-preemptable jobs remain scheduled.
  Definition schedule_respects_preemption_model :=
    ∀ j t,
      arrives_in arr_seq j →
      ~~ job_preemptable j (service sched j t) →
      scheduled_at sched j t.
