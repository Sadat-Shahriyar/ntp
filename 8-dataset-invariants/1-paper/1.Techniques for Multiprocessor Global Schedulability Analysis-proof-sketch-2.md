(*
  ====section==== Core Definitions Needed
  [D1] dbf(task_i, len):
    - What: standard sporadic-task demand bound over an interval of length len.
    - Why: used in I1 and in the A_k bound proof.

  [D2] dbf_prime(task_i, len):  (* Eq. (4) *)
    - What: carry-in demand abstraction over any len ending at a job deadline:
      floor(len / t_i)*c_i + min(c_i, len mod t_i).
    - Why: bounds "with carry-in" work; feeds I2.

  [D3] a_k, t0, t_arr, t_dead, gamma_k:
    - What: failure-scenario scaffolding:
      let t_dead be the first missed deadline of some task_k;
      t_arr := t_dead - d_k; t0 := last idle instant ≤ t_arr;
      a_k := t_arr - t0; gamma_k: intervals of total length (d_k - c_k) inside [t_arr, t_dead) fully busy with others.
    - Why: used to express the necessary work condition and derive the test.

  [D4] work_no_carryin(task_i) := I1(task_i)  (* Eq. (3) *):
    - What: min( dbf(task_i, a_k + d_k), a_k + d_k - c_k ) if i ≠ k;
            min( dbf(task_i, a_k + d_k) - c_k, a_k ) if i = k.
    - Why: per-task bound without carry-in.

  [D5] work_with_carryin(task_i) := I2(task_i)  (* Eq. (5) *):
    - What: replace dbf by dbf_prime as in Eq. (5).
    - Why: per-task bound with carry-in.

  [D6] idiff(task_i) := work_with_carryin(task_i) - work_no_carryin(task_i)  (* Eq. (6) *):
    - What/Why: isolates additional carry-in contribution, used to select top (m-1).
*)

(*
  ====section==== Helper Lemmas (local building blocks)

  [L0] miss_requires_enough_work:
    Inputs: task_k, a_k, t0, t_arr, t_dead, gamma_k.
    Statement (prose): If a job of task_k first misses at t_dead, then
      sum_over_all_tasks I(task_i) > num_cpus * (a_k + d_k - c_k).
    Strategy: Use the fully busy portions [t0, t_arr) and gamma_k to argue total executed work exceeds platform capacity over that length.

  [L1] bound_no_carryin_I1:
    Inputs: task_i (i≠k or i=k), a_k, d_k, c_k.
    Statement: I(task_i) ≤ work_no_carryin(task_i) as defined in [D4].
    Strategy: Arrival/deadline alignment inside [t0, t_dead); cap by interval length; for i=k subtract c_k of the target job.

  [L2] bound_with_carryin_I2:
    Inputs: task_i, a_k, d_k, c_k, t_i.
    Statement: I(task_i) ≤ work_with_carryin(task_i) using dbf_prime per [D5].
    Strategy: Model worst alignment with carry-in at the right edge; count full jobs + carry-in remainder.

  [L3] at_most_m_minus_1_carry_in:
    Inputs: t0, num_cpus.
    Statement: At t0 (an idle instant), at most (num_cpus - 1) tasks are active; hence at most (num_cpus - 1) tasks can be bounded by I2; all others by I1.
    Strategy: By definition of t0 (there is an idle CPU), so not all m CPUs are busy → ≤ m−1 active tasks.

  [L4] rewrite_to_idiff_top_m1:
    Inputs: {work_no_carryin, work_with_carryin, idiff}, num_cpus, a_k, d_k, c_k.
    Statement: From [L0],[L1],[L2],[L3], obtain:
      sum_over_all work_no_carryin(task_i)
      + sum_of_(m-1)_largest idiff(task_i)
      > num_cpus * (a_k + d_k - c_k).
    Strategy: Substitute per-task upper bounds and select the (m−1) largest idiff terms.

  [L5] lhs_linearized_by_dbf:
    Inputs: task set, a_k, d_k, c_i.
    Statement: LHS(Condition 8) ≤ c_sigma + Σ_i dbf(task_i, a_k + d_k),
      where c_sigma is the sum of the (m−1) largest c_i.
    Strategy: From I1 ≤ dbf and I2 ≤ dbf + c_i, and selecting at most (m−1) carry-ins.

  [L6] dbf_affine_upper_bound:
    Inputs: task_i, a_k + d_k.
    Statement: dbf(task_i, a_k + d_k) ≤ (a_k + d_k) * (c_i / t_i) + (t_i - d_i) * (c_i / t_i).
    Strategy: Standard sporadic DBF upper bound; convert to utilization form.

  [L7] isolate_a_k_bound:
    Inputs: c_sigma, u_total, {c_i,t_i,d_i}, m, d_k, c_k.
    Statement: From [L5] and [L6], derive:
      a_k ≤ ( c_sigma - d_k*(m - u_total) + Σ_i (t_i - d_i)*u_i + m*c_k ) / ( m - u_total ).
    Strategy: Rearrange inequality; ensure denominator positive (assume u_total < m).
*)

(*
  ====section==== Main Theorems

  [T1] edf_schedulable_if_condition_8_holds  (* Theorem 2 / Eq. (8) *)
    Preconditions:
      - Modeling assumptions (sporadic, platform, EDF).
      - For all task_k and for all a_k ≥ 0:
          sum_over_all work_no_carryin(task_i)
          + sum_of_(m-1)_largest idiff(task_i)
          ≤ num_cpus * (a_k + d_k - c_k).
    Goal:
      - The EDF schedule is feasible (no deadlines missed).
    Uses:
      - [L0] miss_requires_enough_work (contrapositive).
      - [L1], [L2] to relate I to I1/I2.
      - [L3], [L4] to aggregate and bound the carry-in tasks.
    Proof sketch:
      - Assume a first miss; specialize t0, a_k, gamma_k.
      - From [L0], derive strict ">" inequality.
      - From [L1]-[L4], show LHS miss condition contradicts assumed "≤" condition for all a_k.
      - Conclude no miss possible.

  [T2] finite_a_k_search_bound  (* Theorem 3 / Eq. (9) *)
    Preconditions:
      - Same model as [T1]; assume u_total < num_cpus.
    Goal:
      - It suffices to check Condition (8) only for a_k satisfying:
          a_k ≤ ( c_sigma - d_k*(m - u_total) + Σ_i (t_i - d_i)*u_i + m*c_k ) / ( m - u_total ).
    Uses:
      - [L5] lhs_linearized_by_dbf
      - [L6] dbf_affine_upper_bound
      - [L7] isolate_a_k_bound
    Proof sketch:
      - Bound LHS of (8) by c_sigma + Σ dbf.
      - Upper-bound Σ dbf affinely in (a_k + d_k).
      - Rearrange to isolate a_k and obtain the stated finite bound.
*)
